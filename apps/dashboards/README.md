# Dashboards de Power BI

Los cinco dashboards descriptivos y predictivos definidos en la sección 9 del informe, consumiendo
el modelo estrella de la capa Gold vía Azure Synapse Serverless SQL Pool:

1. `9.1_monitoreo_diario.pbix` — clima, sismos 7d y focos de calor por región.
2. `9.2_historico_tendencias.pbix` — serie multianual de emergencias con inteligencia de tiempo.
3. `9.3_riesgo_dinamico_explicabilidad.pbix` — mapa de `cluster_riesgo`, probabilidad de riesgo y SHAP.
4. `9.4_comparativo_regional.pbix` — heatmap región × mes y ranking por fenómeno.
5. `9.5_impacto_socioeconomico.pbix` — afectados, viviendas afectadas y severidad por región.

# Calidad de datos (Great Expectations)

Suites de validación aplicadas en la transición Bronze → Silver: no nulidad de campos clave
(completitud ≥ 98%), rangos válidos de coordenadas geográficas dentro del territorio peruano, y
consistencia del código Ubigeo contra el catálogo del INEI (100%) — ver secciones 4.4 y 11.1 del
informe.

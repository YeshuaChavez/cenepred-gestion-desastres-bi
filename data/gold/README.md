# Gold

Notebooks Databricks (PySpark) que construyen el modelo dimensional (esquema estrella / constelación
de hechos) sobre Delta Lake: `DIM_TIEMPO`, `DIM_REGION`, `DIM_FENOMENO`, `FACT_EMERGENCIAS`,
`FACT_MONITOREO_DIARIO`, `FACT_PREDICCIONES`. Listo para consumo directo de los dashboards de Power
BI (vía Azure Synapse Serverless SQL Pool), los modelos de `ml/` y el chatbot (ver secciones 5.2,
5.3 y 5.4 del informe).
